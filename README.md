# 기체의 성질 실험실

풍선과 전자저울, 진공기와 밀폐 용기, 삼각 플라스크와 풍선, 끝을 막은 주사기를 이용하는 초등 과학 시뮬레이션입니다. HTML·CSS·JavaScript로 만들었으며, 로그인과 설치 과정 없이 실행됩니다. 학생의 예측과 관찰 기록은 열린 페이지에서 실험별로 유지되고 새로고침하면 초기화됩니다.

## 내 컴퓨터에서 열기

압축을 풀고 `index.html`을 브라우저로 엽니다. 다른 파일을 같은 폴더에 둡니다.

## GitHub Pages에서 열기

1. 압축을 풉니다. `index.html`, `styles.css`, `apparatus.js`, `app.js`, `README.md`가 저장소의 최상위에 오도록 업로드합니다.
2. 저장소의 **Settings → Pages**로 들어갑니다.
3. **Build and deployment**의 **Source**에서 **Deploy from a branch**를 선택합니다.
4. 기본 브랜치(보통 `main`)와 **/(root)**를 선택하고 **Save**를 누릅니다.
5. 배포가 끝나면 Pages 화면에 표시된 주소를 엽니다.

[GitHub Pages 공식 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## 컴퓨터와 태블릿에서 조작하기

- **컴퓨터**에서 마우스로 실험 도구를 조작할 수 있습니다. 키보드는 `Tab`으로 버튼을 이동하고, 방향키로 실험 탭과 압력 슬라이더를 조작합니다.
- **태블릿**에서는 GitHub Pages 주소를 Safari나 Chrome에서 열고 손가락으로 버튼을 누르거나 플라스크와 주사기 손잡이를 끕니다. 좁은 세로 화면에서는 실험 도구와 조작 버튼이 위아래로 배치되고, 넓은 가로 화면에서는 나란히 배치됩니다.
- 화면을 돌려도 같은 페이지에서 진행 중인 실험과 기록이 유지됩니다. 여러 기기에서 같은 주소를 열면 각 기기에서 개별적으로 실험합니다.

## 실험에서 비교할 수 있는 조건

| 실험 | 조작 | 관찰값 |
| --- | --- | --- |
| 기체의 무게 | 빈 풍선을 기록하고 같은 풍선에 공기를 넣어 다시 기록 | 넣은 공기 부피와 풍선 전체 질량 |
| 공기 빼고 무게 재기 | 진공기로 단단한 밀폐 용기의 공기를 빼고 연결을 분리한 뒤 측정 | 용기 속 공기의 압력과 용기 전체 질량 |
| 온도와 부피 | 풍선을 씌운 삼각 플라스크를 얼음 가득 물, 실온 물, 뜨거운 물통으로 직접 끌어 옮김 | 물의 온도와 플라스크 및 풍선 속 공기의 전체 부피 |
| 압력과 부피 | 막힌 주사기의 손잡이를 끌거나 버튼·슬라이더로 압력을 바꿈 | 주사기 속 공기의 압력과 부피 |

진공기 실험의 용기 자체 질량은 120 g이고, 공기가 들어 있는 초기 전체 질량은 123.60 g입니다. 한 번 조작할 때마다 남은 공기 질량이 0.60 g씩 줄고, 5회 조작 후 120.60 g이 됩니다. 용기 부피는 일정하고, 공기는 조금 남아 있습니다.

온도 실험에서는 플라스크를 다른 물통으로 옮기면 풍선이 약 1.8초 동안 부드럽게 커지거나 작아집니다. 변하는 도중 다른 물통으로 옮겨도 현재 크기에서 이어서 변합니다. 물의 온도와 부피 수치는 도달할 모형값을 표시합니다. 물통 사이의 빈 공간에서 손을 놓으면 마지막으로 들어간 물통으로 돌아갑니다. 온도 실험의 ‘실온 물’은 20°C, ‘얼음물’은 0°C, ‘뜨거운 물’은 65°C로 설정합니다. 실험 수치는 비교를 위한 모형값입니다. 질량 실험은 바깥 공기의 부력 영향을 보정한 값을 표시합니다. 온도 실험은 일정한 양의 공기가 물과 같은 온도에 이르렀을 때를 나타내며 풍선의 탄성에 따른 압력 차이는 생략합니다. 주사기 실험은 끝이 막힌 상태에서 천천히 조작해 온도가 일정하다고 가정합니다.
